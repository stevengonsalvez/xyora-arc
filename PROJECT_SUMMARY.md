# Xyora Arc Website - Project Summary

## Quick Overview

**Modern AI/Tech Showcase Website** - Marketing site for Xyora Arc showcasing their AI and technology solutions

**React + TypeScript Stack** - Built with React 18, TypeScript, and Vite for fast development/builds

**Dark Theme Design System** - Comprehensive Tailwind CSS setup with custom color palette (Deep Blue #002B5C, Vibrant Cyan #00B8D9, Electric Violet #8A2BE2)

**Animated & Interactive** - Uses Framer Motion for animations, has carousel components with auto-rotation, and product card displays

**GitHub Pages Deployment** - Configured for deployment at `xyora-arc.github.io/xyora-arc` with Vercel Analytics integrated
